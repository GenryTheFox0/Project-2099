# No game data in this repository

Scope: the public source tree only. The separately prepared payload includes
binary patches with game-derived replacement bytes and is not certified
asset-free. See [THIRD_PARTY_LICENSES.md](THIRD_PARTY_LICENSES.md).

This repository contains the standalone installer source, two donor hash
manifests, UI artwork and build scripts. It does not contain an Xbox 360 ISO,
GOD container, `Default.xex`, PKZ archives, videos or a preinstalled copy of
Spider-Man: Edge of Time.

The public installer downloads a version-pinned PC Edition support payload and
requires the user to select a compatible local Xbox 360 source. Unknown or
modified revisions are rejected before final installation. The installer does
not search for, link to or download game images.
