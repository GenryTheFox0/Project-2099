## Что скачивать

Для обычной установки нужен только:

- `EOTInstaller-v1.0.0-beta.3.exe`

Инсталлер сам скачает `EOT-PC-Payload-v1.0.0-beta.3.zip`, продолжит оборванную загрузку и проверит размер и SHA-256 перед распаковкой.

Остальные файлы на странице релиза:

- `EOT-PC-Payload-v1.0.0-beta.3.zip` — компоненты PC Edition и патчи; вручную скачивать его для обычной установки не требуется;
- `SHA256SUMS.txt` — контрольные суммы установщика и payload;
- `release-manifest.json` — версия, размеры, хеши и список поддерживаемых источников;
- `Source code` — исходный код установщика, а не готовая игра.

## Обычная установка

1. Скачайте `EOTInstaller-v1.0.0-beta.3.exe` со страницы [официального релиза проекта](https://github.com/GenryTheFox/Spider-Man-Edge-of-Time-PC-Edition/releases/tag/v1.0.0-beta.3).
2. Запустите установщик.
3. Выберите язык мастера и игры.
4. Дождитесь загрузки и проверки компонентов PC Edition.
5. Укажите совместимый источник Xbox 360:
   - USA/Europe retail XDVDFS ISO;
   - ZIP целиком, даже если внутри сначала лежит папка `Spider-Man - Edge of Time (USA Europe)`;
   - распакованную папку с `Default.xex` и `Data` либо её внешний родительский каталог;
   - проверенный альтернативный русский GOD/LIVE/XSF через каталог `415608B2/00007000`.
6. Выберите пустую папку установки. Например: `D:\Games\Project 2099`.
7. Нажмите «УСТАНОВИТЬ» и дождитесь окончания проверки.
8. Запускайте игру через `Launcher.exe` в готовой папке.

Не выбирайте корень диска вроде `D:\` и не устанавливайте поверх непустой старой сборки. Инсталлер специально требует отдельную пустую папку, чтобы не смешивать разные версии и не убивать рабочие файлы.

После успешной установки исходный ISO, GOD или распакованная консольная папка больше не нужны. PC Edition работает из выбранного каталога и не зависит от буквы исходного диска.

## Установка с заранее скачанным payload

Этот способ пригодится для медленного Интернета, переноса на другой компьютер или локального архива.

1. Скачайте два файла:
   - `EOTInstaller-v1.0.0-beta.3.exe`;
   - `EOT-PC-Payload-v1.0.0-beta.3.zip`.
2. Создайте отдельную папку для установщика.
3. Распакуйте ZIP рядом с EXE. Должна получиться такая структура:

```text
EOT GitHub Installer\
├── EOTInstaller-v1.0.0-beta.3.exe
└── payload\
    ├── payload-manifest.json
    ├── port\
    └── patches\
```

4. Запустите EXE. Инсталлер найдёт локальный каталог `payload`, проверит его и не станет заново качать гигабайтный архив.

Не переименовывайте каталог `payload` и не вытаскивайте отдельно его внутренние файлы.

Кнопка источника принимает ISO и ZIP напрямую. При выборе папки инсталлер ищет игровой корень на глубине до двух уровней и автоматически открывает единственный ISO/ZIP внутри неё.

## Поддерживаемые источники

Сейчас записаны и проверяются две ревизии:

- `usa-europe-retail` — распространённая USA/Europe retail-версия Xbox 360 в ISO/ZIP;
- `eu-retail` — старая original-language база PC Edition для обратной совместимости;
- `ru-god-alt` — альтернативный русский GOD/LIVE/XSF.

Надписи `LIVE`, `PIRS`, `CON`, расширение файла или похожее имя сами по себе ничего не гарантируют. Установщик проверяет реальные размеры и SHA-256 файлов. Неизвестная, смешанная или уже изменённая сборка будет отклонена вместо того, чтобы молча собрать битую хуйню.

## Что появится после установки

В выбранной папке останется готовая PC Edition, включая:

```text
Launcher.exe
SpiderManEOT.exe
rexruntime.dll
spider_man_edge_of_time.toml
Data\Original\
Data\Russian\
Support\
```

Основной вход — `Launcher.exe`. Отдельные BAT-файлы для обычного запуска не нужны.

Настройки и сохранения находятся здесь:

```text
%USERPROFILE%\Documents\spider_man_edge_of_time
```

Загруженный кэш установщика находится здесь:

```text
%LOCALAPPDATA%\GenryTheFox\EOTInstaller
```

После успешной установки этот кэш игре не требуется. Его можно оставить для быстрой переустановки или удалить ради свободного места.

## Управление

- клавиатура и мышь поддерживаются;
- движение — WASD;
- чувствительность настраивается в лаунчере;
- XInput-геймпад поддерживается;
- подсказки меняются вслед за активным устройством ввода;
- QTE: **B ↔ E** и **Y ↔ MMB**;
- **MMB означает нажатие колёсика мыши**, а не прокрутку.

## Если Windows показывает предупреждение

Установщик пока не подписан коммерческим сертификатом, поэтому Windows SmartScreen может показать предупреждение для нового EXE. Скачивайте файл только с этого GitHub-релиза и перед запуском сравните SHA-256:

```powershell
Get-FileHash .\EOTInstaller-v1.0.0-beta.3.exe -Algorithm SHA256
```

Актуальный хеш установщика:

```text
C0462B2C31F841DF0323DE6226EA5CB4E451C85EBF4C29F77974887CF1F8E5FF
```

Актуальный хеш payload:

```text
13B88F7F6B26D00D97290707008986D7E9A25ED91F2458D50BA631D654EA804D
```

## Если установка оборвалась

- Просто запустите установщик снова: незавершённая загрузка сохраняется как `.part` и продолжается через HTTP Range.
- Если GitHub отдал повреждённый файл, инсталлер не примет его из-за несовпадения размера или SHA-256.
- Если ошибка повторяется, закройте установщик, удалите `%LOCALAPPDATA%\GenryTheFox\EOTInstaller\downloads` и запустите его снова.
- Если источник отклонён, проверьте, что выбрана поддерживаемая ревизия, а не другой регион, модифицированный образ или смесь файлов из нескольких версий.
- Для проверки уже установленной папки можно выполнить:

```powershell
.\Launcher.exe --validate
.\SpiderManEOT.exe --verify-install
```

## Известные проблемы V1 Beta

Переносимая установка не означает, что все аппаратные проблемы уже исчезли. В текущей версии остаются:

- микрофризы на некоторых переходах;
- отдельные жёсткие зависания;
- белые текстуры или белый рендер на части Intel-встроек;
- отдельные белые элементы меню настроек;
- возможные проблемы со звуком на слабых системах;
- аппаратно-зависимое поведение экспериментального DLSS/ReShade-пакета.

Если экспериментальная графическая опция вызывает проблемы, отключите её и используйте обычный D3D12-режим.

## Коротко

Обычному пользователю нужен один файл:

```text
EOTInstaller-v1.0.0-beta.3.exe
```

Запустили → выбрали свою копию Xbox 360 → указали пустую папку → дождались проверки → запустили `Launcher.exe`.
