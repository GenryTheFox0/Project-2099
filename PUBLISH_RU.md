# Публикация v1.0.0-beta.3 на GitHub

1. Используй публичный репозиторий:
   `GenryTheFox/Spider-Man-Edge-of-Time-PC-Edition`.

2. Отправь в репозиторий содержимое исходной папки. Каталоги `payload`, `tests`, `build` и `artifacts` в Git не добавляй — они уже исключены через `.gitignore`.

3. Создай GitHub Release с точным тегом:
   `v1.0.0-beta.3`.

4. Прикрепи к релизу четыре готовых файла из:
   `artifacts/READY_TO_UPLOAD_v1.0.0-beta.3/GITHUB_RELEASE`

   - `EOTInstaller-v1.0.0-beta.3.exe`;
   - `EOT-PC-Payload-v1.0.0-beta.3.zip`;
   - `SHA256SUMS.txt`;
   - `release-manifest.json`.

5. Вставь содержимое `RELEASE_NOTES_RU.md` в описание релиза.

6. После загрузки сверь SHA-256 обоих файлов с `SHA256SUMS.txt`.

Ссылка на payload уже зашита в релизный установщик. Тег, ZIP и EXE после сборки переименовывать нельзя: установщик ищет именно эти имена и иначе получит 404.

Короче: сначала исходники, потом тег `v1.0.0-beta.3`, затем четыре файла релиза и контрольная сверка хешей. После этого страницу можно открывать людям без стыда и без ебучих сюрпризов.
